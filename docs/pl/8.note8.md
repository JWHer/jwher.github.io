# A General Framework in Transition Style

정적분석기의 안전성을 증명하기 위한

## Transitional Semantics

state s = (l, m)
l: program label
m: machine state(memory)

## Concrete Transition Sequence

예제
```python
# label 0
x = input()
# label 1
while x<=99:
# label 2
    x = x + 1
# label 3
```

initial state \empty에서, transition sequence 예제  
input 100일때: $(0,\empty) \hookrightarrow (1, x \mapsto 100) \hookrightarrow (2, x \mapsto 100)$

## Rechable states

합집합

the least solution of
$$
X = I \cup Step(X)
$$
is also called the least fixpoint of F

lfpF.

## abstract semantics

set of states P(LxM) to label-wise collect L \arrow p(M) to label-wise abstraction L \arrow M#.

p(LxM): all states (0, m0), (0, m'0) ...
L\arrow p(M): label-wise collection (0, {m0, m'0, ...})
L\arrow M#: label-wise abstraction (0, M#0)


## Summary
1. define M to be the set of memory states, L be the finite and fixed set of labels
2. define a concrete semantics as the lfp F
3. define its abstract domain and abstract semantic function
4. Check the abstract domains S# and M# are CPOs. and forms a Galois-connection
5. Check the abstract one-step transition and abstract union satisfy
6. Then sound static analysis is defined as follow $\bigcup F^{\#}(\bot)$

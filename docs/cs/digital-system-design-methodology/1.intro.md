## 디자인 재사용
*플랫폼 기반 디자인*

System On Chip(SOC)의 복잡성은 증가하고 있음
- FPGA(Field Programmable Gate Array)
- ASIC(Application Specific IC)

IP(Intellectual Property)

Platform-based Design(PBD)
- 기술적 요구(큰 분량의 제품, 검증 비용 감소)
- 마케팅 요구(빠른 디자인 시간)

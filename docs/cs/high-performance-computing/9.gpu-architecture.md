## Hardware Context Switch
OS가 하는 컨텍스트 스위치와 다름

A warp is a group of instruction execution instances and is the unit of context switch.

NVIDIA = 32
AMD = 64

한 워프에 모든 쓰레드는 같은 명령어를 실행시킴

컨텍스트가 적으면, 워프를 더 많이 올릴 수 있음.
워프가 많으면, stall(메모리 읽기)동안 컨텍스트 교체의 기회가 더 많아짐

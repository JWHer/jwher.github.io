## Tiling (Blocking) for Matrix Multiply

c는 memory mapping이 row major
fortran은 column major

=> 캐시가 한번에 담을 수 있는 크기로 strip mining

Sub-blocks (e.g., 𝐴𝑖𝑗) can be treated just like scalars

𝐶11  = 𝐴11𝐵11 + 𝐴12𝐵21 𝐶12  = 𝐴11𝐵12 + 𝐴12𝐵22
𝐶21  = 𝐴21𝐵11 + 𝐴22𝐵21 𝐶22  = 𝐴21𝐵12 + 𝐴22𝐵22

```c
/* iterations of subblocks */ 
for (ii = 0; ii < N; ii += B) 
for (jj = 0; jj < N; jj += B)
for (kk = 0; kk < N; kk += B)
    /* B x B submatrix multiplications */
    for (i = ii; i < MIN(ii+B, N); i++) 
    for (j = jj; j < MIN(jj+B, N); j++) 
    for (k = kk; k < MIN(kk+B, N); k++) 
        c[i][j] += a[i][k] * b[k][j];
```

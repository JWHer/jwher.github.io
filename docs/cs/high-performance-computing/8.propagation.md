## Back propagation

x, y, z = -3, 4, -5

q(x,y) = x + y
q/x = 1, q/y = 1

f(x,y,z) = (x + y) z = qz
f/q = z, f/z = q

f가 loss function일때, 최소화시키기 위해서
f/f = 1

f/q = f/f * f/q = 1 * z = -5
f/z = f/f * f/z = 1 * q = 1
f/x = f/q * q/x = -5 * 1 = -5
f/y = f/q * q/y = -5 * 1 = -5
=> forward 값을 저장해놔야 함

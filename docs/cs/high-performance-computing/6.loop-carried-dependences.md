## Anti Dependence and Output Dependence
• False dependence
• A dependence that is not related to the execution order of actual operations but rather arises from the reuse of memory locations
• Can be removed with **variable renaming**

• Flow dependence: S1 → S2, S3 → S4
• Anti dependence: S2 → S3

```
S1: t = a + b
S2: sum1 = t + s1 
S3: t = c + d
S4: sum2 = t + s2
```

after renaming
```
S1: t1 = a + b
S2: sum1 = t1 + s1 
S3: t2 = c + d
S4: sum2 = t2 + s2
```

## Loop Fusion
Fusion is illegal if fusing two loops causes the dependence direction to be changed

- dependence가 해결될 수 있음
- branch 줄어듬(for문)
- increment(iteration cond)
- cache hit 가능성이 높음

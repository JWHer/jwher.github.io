### Thevenin

전류와 전압을 구해야 한다.

1. i_test, V_t를 설정한다
2. V=0, I=0으로 두고 V_a를 구한다. v_a = i_test R_t
3. i_test=0으로 두고 V_b를 구한다. v_b = v_oc
4. V_t = V_a + V_b이다. v_t = v_a + v_b = v_oc + i_test R_t

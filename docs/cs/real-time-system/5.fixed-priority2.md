## Schedulale utilization bound
*스케줄 가능 체크의 두번째 방법(충분조건)
= 한번 계산으로 가능(계산량 적음)
= 각자에게 예산(시간, utilization)을 할당해 줄 수 있음

utilization  
$\sum^n_{i=1} {e_i \over p_i} <= \bar{U}_{bound}$

U <= U_b 스케줄 가능
U_b < U 모름
1 < U 스케줄 불가

no-overflow 이론으로 e1=p2-p1, e2=p3-p2, e3=p3-2(e1+e2)=p3-2(p3-p1)=2p1-p3  
*e3=(p1-e1-e2)=2p1-p3

어떻게 최솟값을 찾아야 하는가? n-polynominal 이기 때문에 partial derivate로 계산

$$
{{p_2-p_1} \over p_1} + {{p_3-p_2} \over p_2} + ... {2p_1 \over p_n}
= r_1 + r_2 + ... + {2 \over r_1r_2..r_n}
\\
0 = 1 - {2 \over r_1^2r_2..r_n} \\
$$

ln2=0.69 이하면 몇개의 태스크든 스케줄 가능

## Basic Priority Inheritance Protocol

1. lower priority task blocks higher priority tasks during its critical section(Priority Inversion),
it use inherits the highest priority of all the blocked tasks.

2. When a task exits its critical section, it returns to its normally assigned priority

3. Priority inheritance is transitive.

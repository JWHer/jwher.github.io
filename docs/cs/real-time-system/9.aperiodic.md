## Deferrable Server
=> save the budget
폴링에서 할당한 시간이 쓰이지 않으면 저장했다 뒤에 사용 가능하도록

문제: bundling effect  
저장된 버짓이 마지막에 사용되고, 바로 다음 버짓이 생성되 1번 더 preemption 되는 것
=> periodic task로 계산 불가

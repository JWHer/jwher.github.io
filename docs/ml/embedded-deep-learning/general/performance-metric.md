#### Latency {#latency-head}

<div id='latency'>

***지연시간(Latency)***은 일반적인 관점으로, 시스템에서 일어난 관찰된 물리적인 변화의 원인과 결과 사이의 시간 지연을 말합니다. ***랙(Lag)*** 또한 게임에서 많이 사용되는 용어로, 입력으로부터 시각이나 음향 반응이 일어나는 지연시간을 말하며, 주로 온라인 게임에서 네트워크 지연으로 일어납니다.

[[wiki] latency](https://en.wikipedia.org/wiki/Latency_(engineering))
</div>

## Limit Theory

### Convergence in distribution
Random variable의 수열 $X_1, X_2, ... \{X_n\}$ 의 cdf가 모든 $x$에 대하여,
 $$
 lim_{x\rightarrow\infty}FX_n(x) = FX(x)
 $$
인 경우 $X_1, X_2, ... \{X_n\}$이 $X$로 converge in distribution라고 부르고
$X_n \xrightarrow{d} X$로 표기한다.

### Convergence in Probability
Random variable의 수열 $X_1, X_2, ... \{X_n\}$ 가 모든 양수 $\epsilon$에 대하여,
 $$
 lim_{x\rightarrow\infty}P(|X_n-X| > \epsilon) = 0
 $$
이면, $X_1, X_2, ... \{X_n\}$이 converge in probability라고 부르고, 
$X_n \xrightarrow{p} X$로 표기한다.

*Continuous Mapping Theorem  
모든 함수 g에 대해 다음이 성립한다.
$X_n \xrightarrow{p} X => g(X_n) \xrightarrow{p} g(X)$

cip는 cid보다 강한 조건으로, 다음 정리로 알 수 있다.  
$X_n \xrightarrow{p} X$ 이면, $X_n \xrightarrow{d} X$ 이다.

### Small O_p notation

$X_n \xrightarrow{p} X$ 이면
$X_n = X + O_p(1)$이다.

$X_n - X \xrightarrow{p} 0$ 이기 때문

## Concentration bounds

데이터를 얼마나 수집해야 하는지, failure boundary를 정하기 위해 필요

### Markov inequality
음수가 아닌 Random variable $X$와 $\epsilon>0$에 대하여,
 $$
 \mathbb{P}(X>\epsilon) < {\mathbb{E}[X] \over \epsilon}
 $$

*Example 18p
We toss a fair coin n times. We want an upper bound for the
probability of getting at least 3n/4 heads.

$$
\mathbb(X>3n/4) < {n/2 \over 3n/4} = {2\over 3}
$$

This is a very crude estimate that did not even try to consider any
information about the distribution’s shape.

루즈한 bound. 평균만 알면 이것밖에 적용 불가능

### Chebyshev inequality

어떤 Random variable $X$와 $\epsilon>0$에 대하여,
 $$
 \mathbb{P}(|X-\mathbb{E}[X]| > \epsilon) < {\mathbb{V}[X] \over \epsilon^2}
 $$

*Example 20p

$$
\mathbb{P}(X> {3n\over 4}) < {2 \over n}
$$

#### Gradient {#gradient-head}

<div id="gradient">

여러 입력에 대한 함수 $f: R^n \rightarrow R$ (예, $f(x) = x_1^2 + x_2^2 + 3x_3^2$)의
편미분 ${\partial \over \partial x_i} f(x)$는 점 $x$에서 어떻게 $f$가 바뀌었는지 변수 $x_i$만을 측정합니다.  
기울기 $f$의 $\nabla_x f(x)$는 모든 편미분을 가진 벡터입니다.  

모든 경사의 요소가 0인 점을 임계점(critical point)이라고 합니다.

</div>
